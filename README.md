Инструкция:
1) Откройте Visual Studio
2) Выберите создание консольного приложения
3) Нажмите ПКМ по названию приложения в обозревателе решений, потом выберите "Изменить файл проекта" и замените весь код на тот что находится в конце README, сохраните изменения с помощью Ctrl+S
4) Добавьте код из Program.cs в одноименный файл
5) Сохраните и запустите приложение

<Project Sdk="Microsoft.NET.Sdk">
	<PropertyGroup>
		<OutputType>WinExe</OutputType>
		<TargetFramework>net8.0-windows</TargetFramework>
		<UseWindowsForms>true</UseWindowsForms>
	</PropertyGroup>
</Project>
